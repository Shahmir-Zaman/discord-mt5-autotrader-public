Discord Chrome Extension Setup

        

        
      

      

        
Load the extension directly in Chrome or Brave in 30 seconds:

        
    
          
  1. Open your browser and navigate to chrome://extensions
    2. 
          
  2. Turn ON Developer mode using the toggle in the top right corner.
    3. 
          
  3. Click the Load unpacked button in the top left corner.
    4. 
          
  4. Select the extension folder located at:
    
            
    C:\path\to\discord-mt5-autotrader-public\extension
    
          
    5. 
          
  5. Open Discord Web (discord.com). The status indicator here will turn Active (Green)!
    6. 
        

        

          ⚡ Zero Timeouts & Real-time: The extension uses native DOM MutationObserver inside Discord. New trade signals are relayed with near 0ms latency, completely eliminating CDP scraping, Playwright dependencies, and DevTools port timeouts.
